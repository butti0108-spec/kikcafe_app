# KIKCAFE アンケート＋クーポン試作品（QR → スプレッドシート → 管理アプリ）

お客様がQRコードから回答し、回答と引き換えにクーポンが発行され、お店側がアプリで集計・確認・クーポン管理をする仕組みの試作品です。
質問項目は、依頼者の紙アンケート（Q1〜Q6）に合わせています。

- Q1 性別・ご年齢（年代／男性・女性・その他）
- Q2 誰と一緒に参加されましたか？（1人・仕事仲間・友人・家族・その他）
- Q3 ご来店のきっかけ（ホームページ・SNS・ブログ・紹介・通りがかり・グーグル・グルメ情報サイト・その他／紹介者やその他のメモ欄つき）
- Q4 お店の雰囲気（とても満足〜とても不満の5段階）
- Q6 改善点や感想・KIKCAFEで興味があることなど（自由記入）
- 回答完了時にクーポンを自動発行（次回ドリンク200円引き、番号つき・有効期限30日）。管理画面で未使用／使用済みの管理と番号検索ができます
- クーポン番号は、発行済みの番号と照合してから発行します。かぶった場合は振り直すので、前に出た番号は出ません（デモ動作・本番のApps Script側の両方に実装済み。乱数を強制的にかぶらせるテストでも、振り直しを確認済み）
- 管理画面には「モニター料金（現物払い）の残高 ― 増渕家」の欄もあります。総額（初期値15,000円、変更可）から、使った分をその場で引いて履歴に残す形で、残高がいつでも見えます。試作品ではこの端末内に記録しています。本番ではシート側に持たせて、お店と増渕家のどちらからでも同じ残高が見える形にします
- ※紙アンケートはQ4の次がQ6で、Q5が見当たりませんでした。Q5がある場合は項目を追加します

## 入っているもの

| ファイル | 役割 |
|---|---|
| form.html | お客様が回答する画面（QRコードの飛び先） |
| app.html | お店側の確認画面。開いたときと「更新」を押したときに、新しい回答を取り込む |
| Code.gs | 本番用の受け口（Google Apps Script）。回答をスプレッドシートに登録し、確認画面へ返す |

## いまの状態（デモ動作）

- 送信先の設定（GAS_URL）は本番の受け口に設定済みです（下記「本番の状態」参照）
- デモでは、form.html の送信が「受け箱」の役割を果たし、app.html がそこから取り込みます
- 確認の手順：同じブラウザで form.html を開いて回答 → app.html を開く（または「更新」を押す）と、回答が取り込まれます
- 取り込み済みの回答は二重に入りません（IDで照合）
- app.html には CSV書き出しボタンも付けてあります（Excelで開けます）

## 本番にする手順（Apps Script連携）

1. Googleスプレッドシートを新規作成する
2. そのシートのメニュー「拡張機能」→「Apps Script」を開き、Code.gs の中身を貼り付けて保存する
3. 「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」、実行ユーザー「自分」、アクセス「全員」でデプロイし、発行されたURLを控える
4. form.html と app.html の両方で、冒頭の設定 `GAS_URL` に、そのURLを入れる
5. form.html を公開（GitHub Pages等）し、そのURLでQRコードを作る
6. お客様が回答するとスプレッドシートに自動で1行ずつ登録され、app.html を開く／更新すると取り込まれます

## 注意

- この形は「通信あり版」です。データは一度スプレッドシート（ネット上）を通ります。今の専用アプリ（端末の中だけ・通信なし）とは別枠の仕組みです
- 読み込み口のURLは実質「鍵」になります。個人情報をそのまま扱う場合は、合言葉を付ける等の追加の配慮が要ります
- 質問項目は試作品の仮のものです（満足度／良かった点／おすすめ／年代／ご意見）。用途に合わせて差し替えます
